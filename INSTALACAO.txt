LIVRO PONTO - PROFESSORES EMCA
==============================

1. Crie a pasta:
   C:\Projetos\LivroPontoEMCA

2. Copie os arquivos deste projeto para essa pasta.

3. Abra o PowerShell na pasta:
   cd C:\Projetos\LivroPontoEMCA

4. Crie o ambiente virtual:
   python -m venv .venv

5. Ative o ambiente virtual:
   .\.venv\Scripts\Activate.ps1

6. Instale a dependência:
   python -m pip install -r requirements.txt

7. Confira no arquivo config.py se a pasta de horários continua sendo:
   C:\Users\391665\OneDrive\EMCA\Horários\2026

8. Execute:
   python main.py
